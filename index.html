🌀 AirSense — Air Quality Index Predictor

A 2nd-year B.Tech AI/ML project by Vikranth Reddy. A ridge regression model trained on 600 synthetic city-days predicts the Air Quality Index (AQI) from pollutant and weather readings. 5-fold CV: R² = 0.908, MAE = 19.82 vs a 69.99 mean-guess baseline.

How it works: each input is standardised with the training means and standard deviations, then multiplied by the model's learned coefficients. The exact same weights run in this page and in the Python training script (train.py), so the browser result matches the trained model to within 0.01 AQI points.

AQI guide: 0–50 Good, 51–100 Moderate, 101–150 Unhealthy for sensitive groups, 151–200 Unhealthy, 201–300 Very unhealthy, 301+ Hazardous. Try a sample: PM2.5 180, PM10 320, NO2 90, O3 60, 30°C, 45% humidity, 3 km/h wind → about 238 AQI (Unhealthy).
